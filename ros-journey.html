My ROS 2 Journey

This page documents my transition from embedded-systems development toward robotics and autonomous systems engineering. My learning focuses on ROS 2, robot simulation, state estimation, mapping, localization, and autonomous navigation.

Learning Progression

Completed

01. ROS 2 Foundations

Learned the basic ROS 2 architecture and developed Python-based ROS 2 nodes for communication between robot components.

Nodes Topics Publishers Subscribers Services Parameters rclpy colcon
Completed

02. Robot Simulation with Gazebo

Created and tested a four-wheel mobile robot simulation using ROS 2 and Gazebo. Worked with robot models, simulated sensors, velocity commands, and visualization in RViz2.

Gazebo RViz2 URDF TF2 cmd_vel The Construct
Completed

03. Robot State Estimation

Studied robot pose estimation using wheel odometry and IMU measurements. Implemented sensor fusion concepts using an Extended Kalman Filter.

IMU Wheel Odometry EKF Pose Estimation Sensor Fusion
Completed

04. 2D LiDAR SLAM

Used simulated LiDAR data with SLAM Toolbox to generate a two-dimensional occupancy-grid map. The generated map was saved for later localization.

LiDAR SLAM Toolbox Occupancy Grid Mapping
Completed

05. AMCL Localization

Localized the simulated mobile robot on a previously generated map using the Map Server, AMCL, LiDAR data, and the ROS 2 transform system.

AMCL Map Server LiDAR TF2 Localization
In progress

06. Autonomous Navigation with Nav2

Developing autonomous point-to-point navigation using Nav2. The current focus includes navigation configuration, path planning, controller behavior, goal execution, and obstacle avoidance.
