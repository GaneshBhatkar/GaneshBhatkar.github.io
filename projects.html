▶ Autonomous Navigation using Nav2 Completed

Implemented and validated point-to-point autonomous navigation using ROS 2 Nav2. The system combines global planning, local costmaps, DWB local control, AMCL localization, LiDAR sensing, and velocity control.

Navigation was tested between multiple goal locations, including environments containing obstacles and constrained spaces. The robot successfully avoided obstacles while maintaining safe clearance.
